RM ENTERPRISES - LOCAL TESTING

1. Extract this folder.
2. Double-click START_WEBSITE.bat.
3. It uses the Windows built-in PowerShell server, so Python is NOT required.
4. Wait for the browser to open at http://127.0.0.1:8000/index.html.
5. Keep the black server window open while testing.
6. When finished, run STOP_WEBSITE.bat or close the server window.

IMPORTANT:
- "Not secure" on 127.0.0.1 is normal because this is local HTTP testing.
- If the server cannot start, send a screenshot of the black server window.
